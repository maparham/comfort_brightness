# App Icon + Menu Bar Glyph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AutoBrightness a real app icon (Dock/Finder, both build paths) and a matching code-drawn menu-bar template glyph, per `docs/superpowers/specs/2026-08-05-app-icon-design.md`.

**Architecture:** An SVG under `Resources/Icon/` is the source of truth for the app icon; a script rasterizes it with `NSImage` (CoreSVG, built into macOS) into an `.iconset` and packs it with `iconutil` into `AppIcon.icns`, which both the Xcode target and `Scripts/make-bundle.sh` ship. The menu-bar glyph is drawn in code (`NSImage(size:flipped:drawingHandler:)`, `isTemplate = true`) so it works identically in the bundled and unbundled (`swift run`) cases, and replaces the `sun.max` fallback only — the percentage title stays.

**Tech Stack:** SVG, Swift (AppKit/CoreGraphics), `iconutil`, `xcodegen`, bash.

## Global Constraints

- macOS deployment target: 15.0; Swift 6.0, strict concurrency `complete` (from `project.yml` / `Package.swift`).
- `AutoBrightness.xcodeproj` is a git-ignored build artifact; `project.yml` is the source of truth — after editing it, run `xcodegen generate`.
- No new external dependencies (no `rsvg-convert`/Inkscape — neither is installed; use only stock macOS tools).
- Colors (from the spec, exact): body gradient `#2b3a5c` → `#141d33`; bezel/stand `#e8edf5`; screen `#fdf6e3`; sun `#f7b733`.
- Menu bar behavior: percentage title stays; the custom glyph ONLY replaces the `sun.max` fallback image.
- Both the generated `AppIcon.icns` and its SVG source get committed (builds must not require regeneration).

**Why no unit tests in this plan:** the deliverables are visual assets and drawing code inside an executable target (`AutoBrightnessApp`), which the test bundle (`AutoBrightnessCoreTests`) cannot import. Each task instead ends with a concrete verification command and a rendered-image check. `swift test` must still pass untouched at every commit.

- [ ] **Step 2: Write the generation script**

Create `Scripts/make-icon.sh` (make it executable: `chmod +x Scripts/make-icon.sh`):

```bash
#!/usr/bin/env bash
# Regenerates Resources/Icon/AppIcon.icns from Resources/Icon/AppIcon.svg.
# Uses NSImage (CoreSVG) so it needs no tools beyond stock macOS + Xcode CLT.
set -euo pipefail

cd "$(dirname "$0")/.."

SVG="Resources/Icon/AppIcon.svg"
ICONSET="$(mktemp -d)/AppIcon.iconset"
mkdir -p "$ICONSET"

swift - "$SVG" "$ICONSET" <<'EOF'
import AppKit

let svgPath = CommandLine.arguments[1]
let iconsetPath = CommandLine.arguments[2]

guard let svg = NSImage(contentsOfFile: svgPath) else {
    fatalError("could not load \(svgPath)")
}

// (name, pixel size) pairs for a complete macOS iconset.
let variants: [(String, Int)] = [
    ("icon_16x16", 16), ("icon_16x16@2x", 32),
    ("icon_32x32", 32), ("icon_32x32@2x", 64),
    ("icon_128x128", 128), ("icon_128x128@2x", 256),
    ("icon_256x256", 256), ("icon_256x256@2x", 512),
    ("icon_512x512", 512), ("icon_512x512@2x", 1024),
]

for (name, px) in variants {
    let rep = NSBitmapImageRep(
        bitmapDataPlanes: nil, pixelsWide: px, pixelsHigh: px,
        bitsPerSample: 8, samplesPerPixel: 4, hasAlpha: true,
        isPlanar: false, colorSpaceName: .deviceRGB,
        bytesPerRow: 0, bitsPerPixel: 0)!
    NSGraphicsContext.saveGraphicsState()
    NSGraphicsContext.current = NSGraphicsContext(bitmapImageRep: rep)
    svg.draw(in: NSRect(x: 0, y: 0, width: px, height: px),
             from: .zero, operation: .copy, fraction: 1.0)
    NSGraphicsContext.restoreGraphicsState()
    let png = rep.representation(using: .png, properties: [:])!
    try! png.write(to: URL(fileURLWithPath: "\(iconsetPath)/\(name).png"))
}
EOF

iconutil -c icns "$ICONSET" -o Resources/Icon/AppIcon.icns
rm -rf "$(dirname "$ICONSET")"
echo "Wrote Resources/Icon/AppIcon.icns"
```

- [ ] **Step 1: Write the glyph**

Create `Sources/AutoBrightnessApp/StatusGlyph.swift`:

```swift
import AppKit

/// The menu-bar fallback glyph: a display outline with a small sun inside,
/// matching the app icon's silhouette. Drawn in code so it renders
/// identically whether the executable runs bundled or via `swift run`
/// (an unbundled SwiftPM executable has no resource bundle to load from).
/// Template image: macOS tints it for menu-bar appearance and highlight.
@MainActor
func makeStatusGlyph() -> NSImage {
    let image = NSImage(size: NSSize(width: 17, height: 17), flipped: true) { _ in
        NSColor.black.set()

        // Display outline.
        let screen = NSBezierPath(
            roundedRect: NSRect(x: 1.5, y: 3, width: 14, height: 9),
            xRadius: 1.8, yRadius: 1.8)
        screen.lineWidth = 1.4
        screen.stroke()

        // Base line under the display.
        let base = NSBezierPath()
        base.move(to: NSPoint(x: 6.5, y: 14.5))
        base.line(to: NSPoint(x: 10.5, y: 14.5))
        base.lineWidth = 1.4
        base.lineCapStyle = .round
        base.stroke()

        // Sun disc, centered on the screen.
        NSBezierPath(ovalIn: NSRect(x: 6.7, y: 5.7, width: 3.6, height: 3.6)).fill()

        // Four cardinal rays (diagonals dropped at this size for clarity).
        let rays = NSBezierPath()
        rays.move(to: NSPoint(x: 8.5, y: 4.4)); rays.line(to: NSPoint(x: 8.5, y: 5.2))
        rays.move(to: NSPoint(x: 8.5, y: 9.8)); rays.line(to: NSPoint(x: 8.5, y: 10.6))
        rays.move(to: NSPoint(x: 5.4, y: 7.5)); rays.line(to: NSPoint(x: 6.2, y: 7.5))
        rays.move(to: NSPoint(x: 10.8, y: 7.5)); rays.line(to: NSPoint(x: 11.6, y: 7.5))
        rays.lineWidth = 1.1
        rays.lineCapStyle = .round
        rays.stroke()

        return true
    }
    image.isTemplate = true
    image.accessibilityDescription = "Auto Brightness"
    return image
}
```
